## 二、四步原理（这是最该记住的）

### 第 1 步 · 前向 forward

图片进去，网络输出 **10 个分数**（还不是概率）：

```
飞机 0.3 | 汽车 0.1 | 鸟 1.2 | 猫 4.5 | 狗 2.1 | ...
```

**刚初始化时它什么都不会**，分数是随机的。它只是把像素经过一串乘加运算，算出一堆数。

### 第 2 步 · 损失 loss

图里真实是「猫」，但网络给「猫」打 4.5、给「鸟」打 1.2。

交叉熵损失做一件事：**把「预测分布」和「正确答案」比，算出一个数字**。

```
非常确信是对的  → loss 接近 0
瞎猜（10 类）   → loss 约 2.3（≈ ln 10）
确信错的        → loss 很大
```

**这个数字就是「错得多离谱」的量化。** 实测里 train_loss 从 1.84 降到 1.40，就是「越来越不错」。

### 第 3 步 · 反向传播 backward

网络有 **114,186 个参数**，loss 是它们共同造成的。要知道「每个参数该往哪调」，需要求偏导。

手算 11 万个不可能。**`loss.backward()` 自动做这件事**——沿计算图倒着走一遍，用链式法则把每个参数的梯度算出来，存进 `param.grad`。

> 一句话：**backward 回答「每个参数各自该负多少责任」。**

### 第 4 步 · 更新 step

```python
# optimizer.step() 内部做的就是：
新参数 = 旧参数 - 学习率 × 梯度
```

梯度说「往这个方向走 loss 会变大」，所以往**反方向**走一点（梯度下降）。

学习率（本次用 1e-3）决定「一次走多远」：太大→跨过最低点来回震荡；太小→半天挪不动。

## 三、四步合起来，为什么能学会

```
重复 375 次（8000 张 ÷ 64 一批 × 3 轮）：
    看一批图 → 猜 → 算错多少 → 算出每个参数该往哪调 → 调一点点
```

每次调整微乎其微，但**方向是对的**。375 次之后，参数就挪到了「猜得比较准」的位置。

准确率曲线就是这个过程的证据：43.05% → 46.05% → **53.10%**。

**为什么不是 90%+**：网络太小（11 万参数，真正的 ResNet 有 1100 万）、数据只有 8000 张、只跑 3 轮。这一周的目的是**验证流程对不对**，不是刷精度。

## 四、网络结构

```python
conv(3→32) → BN → ReLU → pool   # 32×32 → 16×16
conv(32→64) → BN → ReLU → pool  # 16×16 → 8×8
conv(64→128) → BN → ReLU → pool # 8×8 → 4×4
flatten → dropout(0.3) → linear(128*4*4 → 10)
```

每一块都是「卷积 → 归一化 → 激活 → 池化」：
- **卷积**：提取局部特征（边缘、纹理）
- **BN**：把数据拉回稳定范围，训练更稳
- **ReLU**：引入非线性（否则多层等于一层）
- **池化**：边长减半，减少计算量

## 五、踩到的坑

### 坑 1：`cuda.is_available()` 返回 False，不是装错了

本机是 AMD Radeon 780M **核显**，没有 NVIDIA 卡。这个返回值 `False` 是**硬件决定的必然结果**。

**别去折腾 CUDA 版本**——那是别人的问题。真要 GPU，用组里的 L20（见 `w2-l20五项补做.md`）。

### 坑 2：`num_workers` 在 Windows 上必须设 0

Windows 的进程启动方式（spawn）与 Linux 不同，多进程 DataLoader 容易崩。

### 坑 3：模型和数据必须在同一个 device

```python
model.to(device)
images, labels = images.to(device), labels.to(device)   # 这句不能忘
```

否则报 `RuntimeError: Expected all tensors to be on the same device`。

### 坑 4：加载权重后要 `model.eval()`

Dropout 和 BatchNorm 在训练和推理时行为不同。忘了切 eval，测出来的数会偏低。

## 六、自测四问

1. `forward` 到 `backward` 之间发生了什么？→ **算了损失，得到一个「错多少」的数字**
2. 为什么 `optimizer.zero_grad()` 不能省？→ **不清空的话梯度会累加，这一轮就算歪了**
3. 学习率调太大会怎样？→ **一步跨过最低点，来回震荡甚至发散**
4. 为什么保存的是 `state_dict` 而不是整个模型？→ **只存参数，加载时不依赖原来的代码结构**
