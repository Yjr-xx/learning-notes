## 二、我实际跑通的第一个脚本

`notes/w1_practice.py` —— 认识 tensor 的练习脚本，用 `.venv` 里的 Python 运行：

```bash
.venv/Scripts/python.exe w1_practice.py
```

它做的事（每段都有 print 解释）：

1. 造一个 2 行 2 列的**小数**表格 `torch.tensor([[1., 2.], [3., 4.]])`
2. 打印 `shape`（几行几列）、`dtype`（小数还是整数）、`device`（在哪算）
3. 换成 `[[1, 2], [3, 4]]`（没有小圆点）→ **dtype 变了**，从 `float32` 变成 `int64`
4. `x + 1` → 每格加 1，形状不变
5. 再造一张 2 行 3 列的表格，确认 `shape = (2, 3)`

## 三、这一节真正记住的三个坑

| 坑 | 现象 | 为什么重要 |
|---|---|---|
| 小数点和没小数点，是两个东西 | `1.` 是小数 `float32`，`1` 是整数 `int64` | 算 loss、准确率必须用小数，用整数精度会被砍掉 |
| 两次除法不一样 | `10 / 3` → `3.333`；`10 // 3` → `3` | 写训练脚本时算平均 loss，用错就永远是整数 |
| 数字和文字长得像，行为不同 | `"5" + 5` 直接报错 | 报 `TypeError: can only concatenate str (not "int") to str` 时，意思是"你在拿文字加数字"，用 `int()` 转一下 |
